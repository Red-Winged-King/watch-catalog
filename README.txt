G-SHOCK PRIVATE ARCHIVE

Open index.html with a local web server (recommended):
  python -m http.server 8080
Then visit http://localhost:8080

Selection code format:
  BAG1.<base64url JSON>
Decoded JSON shape:
  {"v":1,"items":[["ARCHIVE-ID",quantity], ...]}

The site contains only G-SHOCK-family catalog sections and diamond/moissanite covers extracted from the supplied PDF. Rolex, Tissot, Swatch x AP, Moonwatch, electronics, bags, glasses, and other non-G-SHOCK catalog pages were excluded.
